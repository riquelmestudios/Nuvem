# ☁️ Sobre

**Nuvem** é um sistema integrado ao **Riquelme System**, permitindo enviar arquivos diretamente para este repositório do GitHub.

Todos os arquivos enviados pelo bot são organizados automaticamente nas pastas do repositório.

---

# ✨ Recursos

- ☁️ Upload de arquivos
- 📁 Organização automática
- 🤖 Integração com Riquelme System
- ⚡ Upload rápido
- 🔒 Armazenamento no GitHub
- 📦 Suporte para diversos formatos

# 🚀 Como funciona

1. Envie um arquivo para o **Riquelme System**.
2. O bot processará o upload.
3. O arquivo será enviado para este repositório.
4. O conteúdo ficará salvo nas respectivas pastas.
